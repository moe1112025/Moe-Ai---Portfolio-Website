# Moe Htet Ar Kar — Cinematic Engineering Portfolio v5

Professional portfolio for **Moe Htet Ar Kar (Phoe Cho)**, positioned around:

**Cybersecurity Engineer · AI Red Teamer · Penetration Tester**

with an applied engineering track covering Machine Learning, Computer Vision and edge AI.

## Direction

This rebuild keeps the cinematic 3D system but changes the narrative structure:

`Security Core → Assessment Evidence → Applied Intelligence → Engineering Intersection → Credentials → Contact`

Cybersecurity remains the primary role identity. ML/CV/edge projects are presented as supporting engineering practice and active learning work rather than as equal competing career identities.

## Key architecture

- React + Vite
- Three.js / React Three Fiber
- GSAP + ScrollTrigger
- Lenis
- Lucide icons
- Native semantic HTML/CSS
- WebGL fallback
- Reduced-motion fallback
- Responsive project filtering
- PDF preview/open/download workflow
- Image preview modal
- Project technical-detail modal

The cinematic stage uses a continuous 35-node 3D field: 22 security evidence nodes plus 13 applied project nodes represented as the engineering narrative transitions.
